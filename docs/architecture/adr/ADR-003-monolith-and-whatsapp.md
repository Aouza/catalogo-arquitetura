# ADR-003 — Monólito modular e conversão por WhatsApp

**Status:** baseline acordado

## Decisão
Next.js App Router + Supabase em monólito modular; contato via link WhatsApp pré-preenchido; nenhum checkout ou processamento de pedidos.

## Motivos
Baixo volume inicial, cadastro manual, prazo e manutenção simplificados. Sem necessidade de API oficial WhatsApp.

## Consequências
Vendas e disponibilidade real são confirmadas fora da plataforma. Métricas de clique não representam vendas.
