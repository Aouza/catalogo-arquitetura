# Claude Code — contexto do projeto

Leia `AGENTS.md` integralmente antes de alterar código. A documentação de produto, domínio e arquitetura em `docs/` é a fonte de verdade. Consulte `docs/delivery/IMPLEMENTATION_PLAN.md` para identificar a próxima entrega. Não implemente funcionalidades fora do MVP sem autorização. Se um requisito estiver indefinido, consulte `docs/delivery/OPEN_QUESTIONS.md` e solicite decisão.
